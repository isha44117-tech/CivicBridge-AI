# CivicBridge AI 🏙️

### AI-Powered Civic Complaint Analysis and Visualization

CivicBridge AI is a web-based civic technology project designed to help organize civic complaints, analyze reported issues using AI, and visualize complaint patterns through an interactive dashboard.

## 🎯 Problem Statement

Civic issues such as waste accumulation, damaged roads, water supply problems, and faulty streetlights affect communities. Organizing these reports and identifying recurring issues can help make civic problem reporting easier to understand.

## 💡 Our Solution

CivicBridge AI provides a web interface where users can submit civic complaints, receive AI-assisted analysis, and explore complaint information through a dashboard.

## ✨ Key Features

- **Civic Complaint Reporting:** Submit an issue with its description, location, and category.
- **AI-Assisted Analysis:** Generate a summary and suggested priority for a complaint.
- **Authority Suggestions:** Display a suggested department based on the reported issue.
- **Interactive Dashboard:** View complaint records and category summaries.
- **Recurring Complaint Insights:** Identify repeated complaints associated with locations and categories.
- **Map Visualization:** Explore illustrative civic locations and complaint counts.
- **SQLite Database:** Store complaint records locally.
